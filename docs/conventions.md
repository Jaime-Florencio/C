# Convenções do repositório

## Nomes de pastas e arquivos
- Usar minúsculas e hífen (`kebab-case`).
- Prefixar módulos e aulas com dois dígitos para manter ordem didática.

## Convenção para arquivos C/H
- Arquivos-fonte: `assunto-acao.c` (ex.: `vetor-soma.c`).
- Headers: mesmo nome-base do `.c` (ex.: `vetor-soma.h`).
- Arquivos de teste rápido/exemplo: `ex-XX-descricao.c`.

## Convenção para exercícios
- Pasta: `exercicios/` dentro da aula.
- Arquivo: `ex-XX-enunciado-curto.c`.
- Opcional: `ex-XX-resposta.md` para raciocínio.

## Convenção para projetos
- Pasta em `projects/<trilha>/nn-nome-projeto/`.
- Estrutura sugerida: `src/`, `include/`, `docs/`, `README.md`.

## Commits
- Padrões: `docs:`, `chore:`, `feat:`, `refactor:`.
