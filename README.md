## ✅ Convenção recomendada

- Aulas: manter `Aula_<número>-<tema>.md`
- Projetos: um diretório por tema (`10.x-<MCU>`) com código e documentação próprios
- Commits: usar prefixos como `docs:`, `feat:`, `chore:` para facilitar histórico
